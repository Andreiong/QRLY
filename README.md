# Qrly

A minimal URL to QR code generator. Paste a link, style it, and download it as PNG, SVG, or WebP.

## Features
- Two-step flow: enter your link, then customize
- Custom code and background colors, with a contrast check so codes stay scannable
- Dot styles, optional center logo, and a customizable frame with optional text
- High-resolution export (up to 2048 px)
- Runs fully in the browser, so nothing you enter is uploaded
- Interactive connecting-dots background

## Tech stack
Next.js 15, React 19, TypeScript, Tailwind CSS v4, shadcn/ui, qr-code-styling
